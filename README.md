# vos.mojezdravka.cz

Website of **Vyšší odborná škola zdravotnická Suverénního řádu maltézských rytířů** (Žerotínova 1143/38, Praha 3), a nursing college founded by the Czech Grand Priory of the Order of Malta.

It uses the same engine, design system and news workflow as maltezskyrad.cz (and lurdy.eu, velkoprevorskypalac.eu): a Python script (standard library only) turns the files in `content/` into plain HTML in `dist/`. No CMS, no database, no packages to install.

## Commands

```sh
python3 build.py serve 8000      # preview build, served at http://127.0.0.1:8000 with headers and redirects applied
python3 build.py                 # preview build into dist/ (noindex, review labels shown)
python3 build.py --production    # production build (Vercel runs this)
python3 check.py                 # checks dist/: links, redirect targets, one h1, titles, descriptions, brand files, acronym
python3 tests/site.local.py       # dist/ plus the pages rendered from the shared database
```

CI (`.github/workflows/ci.yml`) runs all three on every push.

## Where things are

| Path | What |
|---|---|
| `content/pages/<url>/index.html` | Pages: JSON front matter between `---` lines, then HTML. `description`, `image`, `status`, `nav` (short menu title), `section` (lists its menu children), `note` (review note, not shown). |
| `content/site.json` | Names, contacts, links, menu, news categories.; `supabase` (project address, publishable key, this site's id) |
| `static/media/YYYY/MM/` | Photos and documents (same paths as the old `/wp-content/uploads/sites/4/`). |
| `static/img/logo/vosz.svg` (banner), `vosz-light.svg` (light grounds), `static/img/header/students.webp` | School logo, generated by `tools/make_logo.py` (shared with the Kladno and Skutec school sites), and header photograph (see `docs/brand-compliance.md`). |
| `vercel.json` | Hosting, security headers, all legacy redirects (`docs/legacy-url-map.md`). |
| `tools/import_vos.py` | One-off importer from the old WordPress site. |

## Editorial workflow

**News, events, notices and galleries (no GitHub needed).** Staff publish at `/pridat-aktualitu/` (not linked, not indexed): e-mail, password and a one-time code from an authenticator app. Posts, events and photos go to the shared Supabase database of the three school sites and are on the web within a minute; `api/page.py` renders those pages on request with this site's own functions. Drafts, scheduled posts, pinned notices, roles and user management are described in `docs/publishing.md`.

**Documents.** Put the PDF in `static/media/YYYY/MM/` and link it in a list: `<ul class="files"><li><a href="/media/…pdf">Název dokumentu</a></li></ul>`. The build adds type and size.

**Pages.** Edit the file; set `"imported": false` (already set on all curated pages) so a re-import never overwrites it; remove `"status"` once the school approves the page.

**Rules** (Order of Malta communications policy): full name of the Order where it is introduced, then "Maltézský řád"; never "Malta" alone or an acronym (`check.py` flags SMOM). Never redraw or recolour the shield.

## Security notes

- Headers (`vercel.json`): CSP with no third-party origins and no inline styles or scripts (`'wasm-unsafe-eval'` only lets WebAssembly compile, for the PDF shrinking), HSTS, `nosniff`, `frame-ancestors 'none'`, Referrer-Policy, Permissions-Policy. `check.py` fails the build on any inline `style` attribute.
- Publishing: Supabase Auth with a mandatory second factor; row level security decides who may read or change what (see `docs/publishing.md`); the pages hold only the publishable key; `api/page.py` rebuilds every post text from a tag allowlist before it is shown.
- Quill 2.0.3 (`static/js/vendor/`): CVE-2025-15056 (XSS through its HTML export, no patched release yet). Not exploitable here: the editor's HTML is never rendered unsanitised; `api/page.py` rebuilds it from the allowlist before it reaches any page.
- Ghostscript 10.06.0 as WebAssembly (`static/js/vendor/ghostscript-1.1.0/`): runs only in the staff member's own browser, in a worker that is dropped after one file. Update by replacing the folder with a newer `@okathira/ghostpdl-wasm` build.
